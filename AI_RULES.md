# AI Development Rules

## Before Writing Code

- Search the entire project first.
- Reuse existing components.
- Reuse existing APIs.
- Reuse existing database models.
- Reuse existing services.

## Never

- Duplicate code.
- Duplicate employee roles.
- Duplicate database tables.
- Duplicate API endpoints.
- Duplicate UI components.
- Duplicate prompts.

## Always

- Improve existing code instead of recreating it.
- Keep the architecture modular.
- Keep the project multi-tenant.
- Optimize for Replit Free resources.
- Build for future scalability.

## AI Employees

Every employee must have one clear responsibility.

If a similar employee already exists, improve it instead of creating another one.

## Database

Before creating any table, search for an existing one and extend it if possible.

## Goal

Build one clean, scalable AI Workforce Platform without duplicated logic.
